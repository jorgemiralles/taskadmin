# AGENTS.md

## Project

Vanilla JS/HTML/CSS single-page task management app with a Node.js/Express API backed by PostgreSQL. No build step, no runtime frontend dependencies.

## Commands

- **Serve locally (static + API)**: `npm start` (runs `node server/index.js`, listens on port 8080 by default)
- **Serve statically only**: `python3 -m http.server 8080` (no API; task features require the API)
- **Run e2e tests**: `npm run test:e2e` (Playwright, Chromium; auto-starts the Express server via `playwright.config.js`)
  - On this Alpine box the Playwright-bundled headless shell is a glibc build and won't run (spawn ENOENT). Use the system Chromium instead: `CHROMIUM_BIN=/usr/bin/chromium npm run test:e2e`
- **Postgres**: runs in the `my-postgres-2` container (172.19.0.2:5432); superuser `postgres`/`root`, app role/db `taskadmin`/`taskadmin`/`taskadmin`; schema auto-created by `server/db.js` on startup
- **Connect to Postgres directly**: `PGPASSWORD=root psql -h my-postgres-2 -U postgres` (superuser) or `PGPASSWORD=taskadmin psql -h my-postgres-2 -U taskadmin -d taskadmin` (app role)
- Specs are Gherkin `.feature` files in `specs/start/` (not runnable)
- **No lint or typecheck** configured; CI runs e2e against a Postgres service container on push/PR and deploys to GitHub Pages when tests pass (`.github/workflows/ci.yml`)
- **Deploy to Render**: `render.yaml` defines a web service (`node server/index.js`) plus a managed Postgres. Render injects the production `DATABASE_URL` from the linked database (`taskadmindb_2i4k` on `*.frankfurt-postgres.render.com`) into the service env, so no credentials live in the repo. Add `render.yaml` to the Render service (Blueprint → New Blueprint Instance) or via the dashboard "Deploy from repo"

## Key facts

- All data persisted in PostgreSQL (`tasks` table); API serves it as JSON
- Frontend talks to the API at `/api/tasks`; all task data is persisted in Postgres (no localStorage)
- Task shape: `{ id, title, description, status, createdAt }`; statuses: `prioritize | in-progress | done`
- API routes: `GET/POST /api/tasks`, `GET/PUT/DELETE /api/tasks/:id`, `DELETE /api/tasks` (bulk clear)
- Config via env: `DATABASE_URL` (default `postgres://taskadmin:taskadmin@my-postgres-2:5432/taskadmin`), `PORT` (default `8080`); see `.env.example`
- SSL: `server/db.js` enables `ssl: { rejectUnauthorized: false }` automatically for `*.render.com` hosts (or when the URL has `?sslmode=require`); local Postgres runs without SSL
- Server entry point: `server/index.js` (Express + static); DB pool/schema in `server/db.js`; task routes in `server/tasks.js`
- Task IDs generated by the DB via `gen_random_uuid()`
- XSS prevention: `escapeHtml()` in `app.js` (DOM textContent → innerHTML trick); `escapeAttr()` adds quote escaping for attribute context
- `opencode.json` sets `"permission": "allow"` (commands auto-approved)
- Git workflow: feature branches off `main`; remote `origin` configured; CI deploys to GitHub Pages from `main`
- E2e specs live in `tests/`; `playwright.config.js` targets Chromium with `baseURL http://localhost:8080` (serial, `workers: 1`, shared test DB); tests seed/assert via the API (`tests/helpers.js`)
